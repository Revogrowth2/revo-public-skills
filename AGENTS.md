# REVO Public Skills — manutenção

Este repositório é público. Contém apenas instruções, exemplos fictícios e modelos não preenchidos. Autoria: REVO, Daniel Canton.

- Nunca copiar contextos internos, credenciais, caminhos pessoais, dados de clientes ou logs reais para cá. Não usar o repositório como Brain privado de trabalho.
- Cada skill fica em `skills/<nome>/SKILL.md`, com referências e modelos portáteis. Não exigir ferramentas ou scripts internos da REVO.
- `AGENTS.md` é a fonte de instruções deste repositório; `CLAUDE.md` apenas o importa. Não criar regras divergentes.
- Antes de alterar, defina o resultado e a validação proporcional. Preserve arquivos existentes; não incluir instalação automática, telemetria ou serviços pagos por padrão.
- Distinga compatibilidade por desenho, instrução verificada e teste executado. Não prometer acesso local no browser nem sincronização automática.
- Antes de publicar, revisar TODOS os arquivos staged e histórico Git; conferir links locais, frontmatter, licença e conteúdo do ZIP. Um `.gitignore` não remove arquivo já rastreado.
- Alterar somente este repositório; não mudar visibilidade, permissões ou conteúdo de outros repositórios. Publicação de novas versões requer autorização vigente do responsável.
- Relatos públicos de validação devem usar somente cenários fictícios. O estado privado de manutenção fica fora deste repositório.
